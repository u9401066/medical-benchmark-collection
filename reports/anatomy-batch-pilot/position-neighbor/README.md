# 解剖學雙題提示的題位與鄰題對照

同一道目標題配同一個鄰題，互換前後順序，可以觀察輸入題位與作答的關係。固定目標題在第一或第二位，替換鄰題，可以觀察同一位置上不同鄰題的影響。本批另將目標題單獨作答兩次，記錄相同提示本身的變動。[先導實驗](../README.md)

## 實測結果

六個目標中有兩題在「鄰題 B 在前、目標在後」時改答。其餘三種雙題排列在這兩題上給出相同選項。單題原樣重跑時六個目標的選項全部相同。24 個雙題回覆都依輸入題序列出兩個可解析的答案，兩個單題條件也都完整作答。[原回答與完整數據](results.json)

| 條件 | 目標作答可解析／分派 | 符合來源答案／分派 |
|---|---:|---:|
| 單題 | 6/6 | 2/6 |
| 單題重跑 | 6/6 | 2/6 |
| 目標在前、鄰題 A 在後 | 6/6 | 3/6 |
| 鄰題 A 在前、目標在後 | 6/6 | 3/6 |
| 目標在前、鄰題 B 在後 | 6/6 | 3/6 |
| 鄰題 B 在前、目標在後 | 6/6 | 2/6 |

下表的分母是兩條件均能解析的目標數。事前指定的五個比較各分派六個目標，任一側缺答的配對皆為 0/6。「錯→錯」計入改選，指選了另一個錯誤選項。

| 左條件 → 右條件 | 改選／兩側有效 | 對→錯 | 錯→對 | 錯→錯 |
|---|---:|---:|---:|---:|
| 單題 → 單題重跑 | 0/6 | 0 | 0 | 0 |
| 固定鄰題 A，目標從第一位移到第二位 | 0/6 | 0 | 0 | 0 |
| 固定鄰題 B，目標從第一位移到第二位 | 2/6 | 1 | 0 | 1 |
| 固定目標第一位，鄰題由 A 換成 B | 0/6 | 0 | 0 | 0 |
| 固定目標第二位，鄰題由 A 換成 B | 2/6 | 1 | 0 | 1 |

050 的來源答案為 C。在三種雙題排列中它選對 C，鄰題 035 在它之前時改選 B；該題單獨作答也選 B。074 的來源答案為 A，其他排列皆選 B，鄰題 017 在它之前時改選 C。兩列各有 2/6 改選的比較指向同樣兩題，不能當成四個獨立觀察。相對於單題，四種雙題條件各有 1/6 改選，前三種是 050 由錯改對，最後一種是 074 改選另一個錯誤選項。[逐題比較](results.json)

題位同時影響讀到鄰題的次序與生成作答的次序。本次每種配對只跑一次，六個目標共用六個鄰題；觀察到的差異限於這些題目、排列與後端設定。

## 試驗設計

在 MMLU 作者的英文 anatomy test 共 135 題中，依固定亂數種子 `2026112606` 抽取 6 個目標與 6 個相異鄰題。每個目標配兩個鄰題，代號 A、B 表示鄰題身分。每個鄰題在 A 和 B 各擔任一次，全部選題與排程在推論前固定。下表使用 `anatomy-test-` 後的題號。[作者題庫](https://github.com/hendrycks/test) · [抽樣與排程程式](run.py)

| 目標 | 鄰題 A | 鄰題 B |
|---:|---:|---:|
| 056 | 087 | 012 |
| 074 | 012 | 017 |
| 050 | 017 | 035 |
| 047 | 035 | 125 |
| 051 | 125 | 045 |
| 104 | 045 | 087 |

每個目標接受六個條件：單題兩次、搭配鄰題 A 的第一與第二位、搭配鄰題 B 的第一與第二位。排程共六輪，每輪每一目標與每一條件各出現一次，輪內打散順序。單題兩臂的名稱用於配對，實際先後由排程決定。共 36 次獨立請求，含 36 次目標題及 24 次鄰題作答。評分只看目標題；鄰題作答保留在逐筆紀錄。

使用同機 Qwen2.5 1.5B Q4_K_M、llama.cpp b12776（`e38ea719b`）、4 條 CPU 執行緒、1 個 slot、context 4096、GPU offload 0 層。每次用全新對話、同一英文提示格式、temperature 0、推論 seed `20261126`，單題與雙題的輸出上限均為 128 tokens。模型只收到題號、題文及選項。計分採作者選項答案；醫療內容的當代臨床有效性由另一條審查流程處理。[模型與題源指紋](../README.md#環境與資料) · [逐筆回答、指紋與分母](results.json)

## 重現

在專案根目錄用作者版本的 `anatomy_test.csv` 還原完整 test split。此次已實際從 CSV 重建：原始 CSV SHA-256 為 `966dfd5c4579885ebdb8c05d6754ae5834f672632586d8595be3c0f9360e6f4e`，正規化題本為 `208f9eb5252cceef95ab71e7ff17dd530ad9820167078b7483cb6447c6eb8ca8`。離線驗證器重建六輪排程、兩個鄰題、目標題來源答案與每次提示，重新解析原回答並核算每項比較。SHA-256 同時核對完整題本、每次提示與有文字回覆的原始答案。時間與 token 用量保留為後端和客戶端的觀測值。[作者資料包](https://people.eecs.berkeley.edu/~hendrycks/data.tar)

```sh
python scripts/prepare_mmlu_anatomy.py anatomy_test.csv --split test --out data/anatomy-test.jsonl
python reports/anatomy-batch-pilot/position-neighbor/run.py --items data/anatomy-test.jsonl --verify reports/anatomy-batch-pilot/position-neighbor/results.json
```

重新推論可另開終端機啟動同版伺服器，從用戶端執行下列指令。輸出請選新路徑，完成後可關閉此次啟動的伺服器。

```sh
llama-server -m model.gguf --alias qwen2.5-1.5b-local --host 127.0.0.1 --port 18139 --ctx-size 4096 --parallel 1 --threads 4 --threads-batch 4 --n-gpu-layers 0 --no-webui
python reports/anatomy-batch-pilot/position-neighbor/run.py --items data/anatomy-test.jsonl --run data/anatomy-position-repeat.json
```
