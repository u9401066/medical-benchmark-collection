# 從哪份文件能查到當日適用的成人健檢資格？

在臺灣成人預防保健的同一病例家族，兩個 36 歲個案分別適用一般資格與小兒麻痺的年度資格。各以繁中、美式英文詢問 2024-12-31 與 2026-11-26 的規則，另以兩種語言詢問一般個案在 2025-01-02 的資格，共 10 個查詢。這批評的是排在前面的**來源段落能否支持該日、該族群的判斷**。病例、選項及編者擬答可另外交給醫師核對，兩題的 4 個語言版本均待審。[雙語審題單](../../docs/review/tw-adult-preventive.md) · [逐查詢來源排序及支持判斷](results.json)

## 為什麼要查兩個日期

衛福部在 **2024-12-25 公布、2025-01-01 生效**的修正令，規定一般 30 至未滿 40 歲者每五年可接受一次服務，年滿 35 歲且具小兒麻痺身分者則可每年一次。公報第 1 頁載明生效日，第 101、102 頁的兩個資格格各自支撐一種判斷。國健署另在 2025-01-14 發布新制說明。對 2024-12-31 的現行給付，12 月公報可以說明下一天將生效的改制，該日適用的依據仍須回到舊制。對 2025-01-02 的一般資格，公報已生效，1 月 14 日的說明當時尚未發布。[正式令及附表六之二](https://gazette.nat.gov.tw/EG_FileManager/eguploadpub/eg030242/ch08/type2/gov70/num26/Eg.pdf#page=101) · [國健署 2024 年說明](https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=4809&pid=18071) · [2025 年 1 月 14 日報導](https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=4878&pid=18755)

完整索引有 7 份來源，含這份公報、四份成人健檢網頁與兩份同機關大腸癌篩檢網頁。一個公報 ID 同時定位生效條款與兩個資格格。排序單位是登錄的證據段落組合。編者為各查詢列出可接受的來源 ID；同一份文件是否足以支持個案，取決於登錄段落所涵蓋的族群及日期。未註明刊日的現行服務表只能證明在 2026-11-26 查核時可取得。較早網頁版本依發布者標示的刊登或更新日判定，原始 HTML 均於 2026 年取得。[來源登錄](corpus.json) · [可離線取用的詞彙索引及定位](index.json)

## 同一組題目的檢索結果

下表每種語言各有 5 個查詢，在完整索引中都有依據。首筆命中指第一名為可接受來源，前三筆命中以相同分母計。沒有候選的查詢仍列入分母。「首筆晚於詢問日」依該文件版本可取得日計算。

| 排序條件 | 繁中首筆 | 英文首筆 | 繁中前三筆 | 英文前三筆 | 首筆晚於詢問日，兩語合計 |
|---|---:|---:|---:|---:|---:|
| 詞彙比對 | 2/5 | 0/5 | 3/5 | 0/5 | 4/10 |
| 限當時可取得的文件 | 3/5 | 0/5 | 5/5 | 0/5 | 0/10 |
| 加上四個英中詞語對照 | 3/5 | 3/5 | 5/5 | 5/5 | 0/10 |
| 再排除尚未生效的命令（事後探索） | 5/5 | 5/5 | 5/5 | 5/5 | 0/10 |

第三種條件下，四個 2024-12-31 查詢都把次日才生效的公報排第一。第四種是在看過這個錯誤後追加的規則，只用於詢問當時適用給付的任務。10/10 是在同一個病例家族上得到的檢索結果，沒有模型作答或醫師臨床成績。要驗證這項規則能否泛用，需固定做法後改用其他政策家族，另包括詢問「未來將如何變更」的題型。[逐筆名次與日期旗標](results.json)

移除公報再跑相同的 10 個查詢時，8 個仍有可接受的依據。另 2 個正是 2025-01-02 的一般資格題。在第四種條件下，這兩題仍都搜得到舊文件，但指定庫中可支持該日期與族群的段落為零。評量完整 agent 時，應分別記錄是否取回候選、是否附上合適段落、是否在證據不足時明確交代限制。可另以公報補回後的同一題對照。此處的缺口僅描述這份固定索引。[有無公報的兩組排名](results.json)

## 如何重跑或送入自己的檢索結果

排序使用 NFKC 正規化的中文連續雙字、英文詞及數字，以查詢和文件詞彙集合的 cosine similarity 排名，零重疊時不回傳候選，同分時依來源 ID 排序。輸入取題幹，文件取原標題與固定段落。詞語對照只展開查詢中出現的「成人預防保健、小兒麻痺、國民健康署、公費」四個概念，沒有病人應得的年齡或間隔。[執行程式及對照詞](run.py)

在儲存庫根目錄執行前兩行即可離線複核全部名次並取得給受測者的題本。若使用其他檢索器，為每個查詢輸出一列 JSONL，例如 `{"id":"mbc-tw-adult-0001-zh-TW@2025-01-02","ranking":[]}`。第三行對完整來源庫計分，會區分明示空清單及未提交查詢，並保留全部分派題數。逐題金標屬公開開發資料；進行盲測時只向受測端提供題本與候選文件。

```sh
python reports/tw-preventive-source-pilot/run.py --verify
python reports/tw-preventive-source-pilot/run.py --tasks --out data/preventive-tasks.json
python reports/tw-preventive-source-pilot/run.py --score-rankings data/retriever-rankings.jsonl --out data/retriever-report.json
```

安裝專案的 `.[build]` 後，以下命令從七份官方原件重建索引。若已有原始檔，可加 `--cache data/temporal-sources`，檔名對照在來源登錄的 `cache` 欄。HTML 逐件驗證唯一定位與段落指紋，容許頁面點閱數改變。公報 PDF 驗證原檔 SHA-256，再按三個頁面座標擷取文字並核對合併指紋。索引改動時應重新核對來源及病例。所有輸出使用新檔名。[PDF 擷取程式](gazette.py)

```sh
python reports/tw-preventive-source-pilot/run.py --build-index --out data/rebuilt-preventive-index.json
python reports/tw-preventive-source-pilot/run.py --verify --index data/rebuilt-preventive-index.json
```
