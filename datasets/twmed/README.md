# twmed-v1：台灣醫事人員國考繁體中文選擇題庫（2024–2026）

由 [考選部考畢試題查詢平臺](https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx) 公布的試題、標準答案與更正答案自動建置。
範圍是民國 113–115 年（2024–2026）全部 18 場醫事類專技人員考試的單一選擇題，每題都保留原始出處。

| 檔案 | 內容 |
|---|---|
| `twmed-v1.jsonl.gz` | 題庫，每行一題，依 id 排序（gzip mtime 固定為 0：同樣的輸入會產生位元相同的檔案） |
| `sources.tsv` | 建置時下載的 1,056 個 PDF：考試、類科、科目、檔案種類（Q 試題、S 答案、M 更正答案）、網址、SHA-256 |
| `build_log.json` | 每份考卷的處理結果、每一題被排除的原因、重疊檢查使用的參考資料與其雜湊 |

## 題目格式

```json
{"id": "115020-301-0101-001", "group": "twmed_md", "lang": "zh-TW", "kind": "mcq",
 "question": "顏面神經的感覺根（sensory root of facial nerve）主要將接收到的感覺訊息直接傳入下列腦幹內的那兩個神經核？",
 "options": {"A": "…", "B": "…", "C": "…", "D": "…"}, "answer": "A",
 "meta": {"exam_code": "115020", "exam": "115年第一次專門職業及技術人員高等考試…", "year": 2026, "session": "一",
          "category": "高等考試_醫師(一)", "profession": "醫師", "subject": "醫學（一）（包括生物化學、解剖學…）", "number": 1,
          "depends_on_previous": false, "source": "https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?t=Q&code=115020&c=301&s=0101&q=1"}}
```

`id` 是「考試代碼-類科代碼-科目代碼-題號」，可直接對回原始 PDF。上標寫成 `^`（例如 `1.7×10^10`、`^99mTc`）。
Symbol 字型與 PDF 私用區字形會轉回 Unicode（μ、σ、≤、①…）。`depends_on_previous` 標記「承上題」，共 177 題。

## 篩選規則（只收錄以純文字就能作答、答案唯一的題目）

| 排除原因 | 題數 |
|---|---:|
| 題目範圍內有圖片（結構式、影像、圖表） | 1,162 |
| 文字提到圖（如圖、下圖、箭頭、X 光片…） | 1,031 |
| 題目範圍內有表格框線或分數線（攤平成一行會失去結構） | 443 |
| 更正答案：多個答案均給分 | 207 |
| 更正答案：一律給分 | 130 |
| 選項空白（選項是圖片） | 95 |
| 與 MedQA-TW（train／validation／test）或 TMMLU+ 醫學科目的題目相同 | 38 |
| 無法對應的字形（數學字型亂碼） | 6 |
| 找不到四個選項 | 2 |

另外有三項檢查：
- **答案以更正答案為準**。「第 N 題答 B 給分」這類單一答案更正會套用；多答案、一律給分與複選題一律排除。
- **整份考卷驗證**。題號必須是連續的 1..N，且 N 等於答案卷的題數，否則整份不收。混合卷只取「測驗題」部分。
- **重複題**。同一份 PDF 列在不同類科時只收一次；同一題（題幹與選項相同）也只收一次。

## 法律依據與引用

- 依法令舉行之各類考試試題不得為著作權之標的（**著作權法第 9 條第 1 項第 5 款**），因此本題庫以這些試題建置並公開。
- 考選部網站聲明：「本網站資料，歡迎朋友連結使用。但引用時，請註明資料來源並請確保資料之完整（包括本項宣示在內），均不得任意增刪」。
  本題庫依以上原則處理：
  - 每題都附原始 PDF 網址與題號，題目與選項文字未經改寫，只做格式正規化（換行、空白、上標、字形對應）。
  - 被排除的題目全部列在 `build_log.json`，並說明原因。
- 引用：考選部考畢試題查詢平臺（2024–2026 醫事類專技人員考試），經 medqa-bench twmed-v1 整理。

## 重建

```bash
uv pip install -e '.[build]'          # PyMuPDF（解析 PDF）
medbench twmed-build --years 2024,2025,2026 --out datasets/twmed --cache data/twmed-pdf
sha256sum datasets/twmed/twmed-v1.jsonl.gz
```

- 建置時會向考選部送出約 1,100 個請求，每秒最多 1 個。
- 同樣的 PDF 會產生位元相同的題庫檔。考選部之後若更新 PDF（例如追加更正答案），`sources.tsv` 的雜湊可以看出差異。
- 解析程式在 [medbench/twmed.py](../../medbench/twmed.py)。目前支援的排版：
  - 三種產生器：Microsoft Print to PDF、Gaaiho（私用區選項字形、雙欄選項、右對齊題號）、Chrome。
  - 申論加測驗的混合卷。
