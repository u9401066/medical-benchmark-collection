# 單題公告與答案卷對照

[items.jsonl](items.jsonl) 每行是一筆經查核的公告、訴願案件或更正表紀錄。可用逐題資料的 `item_id` 查到該題的決議、原文網址、證據位置及 S、M 兩份答案卷。沒有對照紀錄的題目，狀態一律為「尚未完成獨立公告比對」。[scope.json](scope.json) 記錄本批查核範圍與數量。

| 實例 | 可查證的結論 |
|---|---|
| 牙體技術學（四），`111110-109-0804-046` | 訴願決定書記載疑義會議維持 C。原答案表與更正表第 46 題均為 C。同一更正表另有第 1、17、18 題的變更，這三題的來源階段標為「同份更正表」，各自保留作答規則。 |
| 社會工作，`112110-103-0301-034` | 邊界案例。最初的新聞稿說明正在研議爭議。後續公告決議一律給分，可對回原答案 C、更正表的 `#` 與該題備註。 |
| 民國 90 年醫師第二階段檢覈筆試 | 外科學等科第 10 題與婦產科學等科第 13 題有主管機關案卷可查，目前保留原文科名、題號、機關處理與後續審判結果。尚缺能唯一對應考畢試題平臺試卷的官方代碼，`item_id` 留空。 |

`documents` 保存決議及先前說明的角色、文號或公告 ID、日期、網址、雜湊與定位。`answer_sources` 分列曾核對的 S、M 檔及本次下載清冊的對應版本。`ledger_item` 包含可比對的原鍵、更正鍵、備註及解析規則。若公告原件與清冊版本不同、原檔未到齊、逐題紀錄過期或規則不一致，`grid_comparison` 會分別指出原因。同一題可能有不同階段的紀錄，解讀時請同時查閱日期及文件種類。

對照程式以官方試卷代碼、題號與來源 SHA-256 定位，並比對已提取紀錄引用的答案檔版本。案件中披露的請求、初步說明與決議保留各自的出處。僅公布全國合計的公告保存在 [scope.json](scope.json)，不分配至單題。逐案整理的來源清單在 [decisions.json](../notices/decisions.json)。

在 repo 根目錄執行 `python -m medbench.moex_rulings` 即可由已公布的官方索引、附件清冊、逐題紀錄與決議重建對照。使用其他批次時可分別指定 `--index`、`--manifest`、`--items`、`--decisions` 及 `--out`。
