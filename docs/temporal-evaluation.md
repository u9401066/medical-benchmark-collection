# 如何評估會過時的醫學題

本方案檢驗微調後的模型能否在指定日期與地區給出有根據的答案，以及原選項皆不適用時，能否說清楚原因。Martínez García 等人追蹤四份指引的 113 項建議，其中 25 項需要更新。這項研究支持逐條追查題目依據，其比例僅適用於該研究樣本。[原始研究，PMID 25200758](https://pmc.ncbi.nlm.nih.gov/articles/PMC4216254/)

## 先固定評分依據

MedChangeQA 實檔提供三種可分開抽核的轉變。512 列中有 115 列在支持與反對間改判，160 列改為證據不足，另有 237 列從證據不足改為可判定。要量測模型過度修改正確答案的傾向，還需另抽答案穩定的對照。這份 CSV 也缺逐題日期和文獻識別碼，所以要先找回各版回顧才能建立臨床答案。[版本、交叉表與重跑方法](review/medchange-audit.md)

題面明示判斷日期、地區、可用資料或工具。同一題可以有「依當年考試規則」與「依指定日期的臨床證據」兩種任務，各自保留題目版本、適用的答案與理由。舊考試一律給分是行政判定。若要測量當時臨床知識，仍需醫師另審。若是考歷史，僅提供當時已公開的證據。

| 醫師審定的題況 | 可得分的行為 |
|---|---|
| 有可接受的選項 | 選到核准答案。先區別「任列一項均可」與「須選出所有正解」，依題意比對集合。 |
| 每個選項都不成立 | 明確指出無有效選項，說明哪個條件已改變，並符合已審理由。 |
| 題幹資訊不足 | 指出影響作答的具體缺項，例如必要的圖表或病例條件。 |
| 證據互相矛盾或編者尚未裁決 | 保留待審並揭露數量，裁決前暫停臨床計分。經審查、刻意測量「應揭露爭議」的題目可另訂評分準則。 |

每種題面都提供相同的回覆選擇。解析失敗、逾時、漏答及單純表示「不知道」各自記錄。已核准且分派給模型的題目均進入主要分母，技術失敗計為未完成、未得分。現有執行器產生單一選項預測。下列臨床判分器可處理另行收集的結構化回覆。[現有執行器](../medbench/runner.py) · [編題與核准流程](editorial-workflow.md)

## 核心指標

逐句詳解與書目查核可從凍結題本產生醫師審閱表。回答格式失敗但有原文時仍可核對理由，查無引用的記錄保留不確定性。報告另列人工審過的回答和參考主張分母。[逐句判讀與工作表操作](rationale-review.md)

| 指標 | 分子與分母 |
|---|---|
| 現行作答達標率 | 符合該題審定行為及必要理由的題數／全體已分派可計分題。原考試分數另報。 |
| 正確棄答率／不當棄答率 | 在應指出無有效選項或缺資料的題中，正確指出原因的比例，兩類分列。另於有可接受選項的題中，計模型明確棄答的比例。 |
| 作答覆蓋率及已選答案錯誤率 | 提出實質選項的題數／可計分題數，以及錯選題數／提出實質選項的題數。兩者並列，使一律棄答的模型可被辨識。若用信心門檻，先在開發集決定，再比較相同覆蓋率的錯誤率。[選擇性預測研究](https://arxiv.org/abs/1705.08500) |
| 過時答案沿用率 | 只取當年與現行答案確實衝突的題，計仍選已失效舊答案的比例。逐題標出新版是否已無可選答案。 |
| 詳解的證據與臨床錯誤 | 醫師先列必要主張，計有適用原文支持的必要主張數／全部必要主張數。另抽核模型額外提出的主張，逐句區分有支持、與證據矛盾、目前無法核實。查驗文獻是否存在、定位是否正確、證據日期與適用族群是否相符。另報含已證實虛構引用或嚴重錯誤主張的回答比例，附人工受審分母。無法取得原文者保留待定。[ALCE 引用評估](https://aclanthology.org/2023.emnlp-main.398/) · [HealthBench 的醫師評分準則](https://arxiv.org/abs/2505.08775) |

分母為零時呈現「無可估計」。正確選項與捏造文獻可能同時出現，因此選項判分與詳解判分各有紀錄。

## 對一份已分派題本計分

在推論前以 `clinical-development` 或 `clinical-evaluation` 固定實際要分派的完整 JSONL 清單，保存 Git 版本及匯出日期。每次計分使用同一個 split 和匯出日。只把題目的 user 訊息送給模型。參考答案、主張與證據留給評分者。歷史重現使用當時凍結的題本；新評測應先依現行證據重新匯出。[時效與用途的匯出條件](editorial-workflow.md#臨床時效維護)

每份模型回覆在 `predictions.jsonl` 占一列。評測端填入題本的 `id`、`content_sha256`，保存原始回答 `text` 及可核對原文的 `response_type`。選擇選項使用 `select` 加上 `selected_options` 字串陣列，例如 `["A","C"]`。其他回應類型有 `no_valid_option`（沒有適當選項）、`insufficient_information`（缺少必要資料）、`abstain`（泛稱不知道）及 `free_text`（實質開放回答）。作答逾時與解析失敗分別記 `timeout`、`parse_error`。題本中有分派、結果檔卻沒有對應列時，工具記為 `missing`。轉錄需保留原回答，遇到無法無歧義解析的文字就記解析失敗。

在分派當下保存整份題本的 SHA-256，作答後以已保存的值核對。題本即使少一題或只有換行改動，比對都會中止；報告的 `gold_sha256` 保存實際讀到的檔案指紋。以下為 PowerShell 範例。

```powershell
New-Item -ItemType Directory -Force data/run | Out-Null
(Get-FileHash data/curated/clinical-dev.jsonl).Hash | Set-Content -Encoding ascii data/run/assignment.sha256
```

```powershell
$assignmentSha = (Get-Content data/run/assignment.sha256 -Raw).Trim()
python -m medbench.clinical_score --gold data/curated/clinical-dev.jsonl --expected-gold-sha256 $assignmentSha --predictions data/run/predictions.jsonl --out data/run/clinical-score.json
```

報告列出每題的結構判定、臨床結果及待審 ID。醫師可依 ID 對照匿名回答與題本的詳解、主張、來源定位和評分準則。每份複核在 `reviews.jsonl` 記下 `id`、報告提供的 `prediction_sha256`、`reviewer`、ISO 日期 `date`、`verdict` 與 `reason`。裁決使用 `pass`、`fail` 或 `undetermined`。加上 `--reviews data/run/reviews.jsonl` 重跑同一指令。若回答、題本內容指紋或轉錄欄位更動，舊裁決的指紋不符，工具會要求重新核對。[臨床判分器](../medbench/clinical_score.py)

機器核對選項或回覆類型。無有效選項、資料不足的辨識比例分列，在可選題中明確棄答的比例另列，技術失敗保留在分母。開放作答的內容交由醫師裁決。符合結構的答案要再經醫師認定達到臨床答案及詳解要求，才計為 `pass`。若尚有待審項目，`confirmed_clinical_pass_share` 僅顯示全體已確認達標的占比，`clinical_pass_rate` 留空。每題可按家族及語言回溯。逐主張證據與書目查證可用同一份原始回答產生獨立閱卷表。新舊標註微調模型的比較，仍需取得具名核准的保留病例與配對回答。

`obsolete_option_reuse` 只計可定義的歷史單選比較。編者先在 `historical_basis.comparison` 標示 `same_decision_single_option`，確認前後問的是同一族群與決策、選項意義相同，且舊正解有日期、出處和定位。醫師審定後，開發或保留評估題本會附上舊選項。分母為舊選項已完全失效的所有已分派版本，分子為作答時只選該舊選項的版本。另以 `obsolete_case_families` 記錄這些版本來自幾個病例家族。例行篩檢間隔仍然有效的控制題、缺乏歷史紀錄的題，以及舊選項仍是新多選答案一部分的題，均另列。漏答、格式失敗與選了其他錯誤選項仍進入適用分母，因此要併讀技術失敗與臨床達標指標。舊凍結題本缺少可比性標記時依 `undocumented` 列出。給分或撤題等行政決議無法作為此指標的歷史正解。[已標記的公費篩檢對照題](review/tw-fit-controls.md)

`selection_coverage` 的分母是全體指派，含開放題及技術失敗。分子只計 `select` 且所有不同標籤都確實出現在題面的作答。題面沒有選項卻輸出代號、輸出不存在的代號、重複標籤或空集合都計入 `selection_counts.invalid`，該題仍留在主要分母。實際選到題面選項但答案或組合錯誤，計入 `selected_answer_error`。舊題本缺 `offered_option_labels` 時，可核實的標籤僅限原已記錄的有效選項；其餘無法確認的選擇標為 `unverified`，該批的選項覆蓋率與已選答案錯誤率留空。

醫師裁決日期必須介於凍結題本的 `export_as_of` 和本次計分日之間，含首尾兩日。`--score-as-of YYYY-MM-DD` 可指定今日以前的結算日，預設今日。歷史題本已到複審日，仍可重評當時凍結的回答。新版題本會按匯出日驗證該用途的權利依據。若歷史匯出完全沒有權利欄位，報告逐題註記 `legacy_undocumented`，此結果僅供重建當時評估。新的分派應從權利已確認的嚴格匯出重新建立。

## 用有限醫師工時做第一輪比較

1. **鎖定樣本與對照。** 先定義母集，按改答、無有效選項、缺資料及答案穩定分層隨機抽病例家族。兩個模型共用相同家族、題目版本與檢索截止日。依科別、語言及區域報告樣本量。稀少類可加抽並單列。估整體比例時按母集層別加權。合成壞選項與真實指引改版分開報告。同病例的翻譯、舊題與改寫留在同一資料分割，保留集不回流微調。若要歸因於時間標註，另比較使用舊標註和更新標註的微調組，固定基礎模型、樣本家族與訓練預算。
2. **先自動比對，再盲審詳解。** 程式比對選項、列出日期／版本差異、逐條連到證據原文。優先送審疑似嚴重錯誤、答案翻轉、新增無有效選項及引用衝突。另從包含兩模型都答對在內的其餘回答隨機抽核，保存抽樣機率，專案整體比率使用對應權重。隱去模型名稱，隨機安排兩模型回答的顯示順序。分歧交第二位臨床審查者獨立判讀、記錄裁決。追蹤每題中位審查分鐘數、每醫師小時確認的錯誤數及抽核發現的漏報。
3. **配對比較。** 每個病例家族只有一項獨立二元結果時，可沿用精確 McNemar 檢定。含同一病例多個日期或翻譯時，依原抽樣層重抽整個病例家族，同時保留兩模型的配對結果，報加權差值與 95% 信賴區間。逐項公布改善、退步與未完成數。主分析依事前分派清單補列缺失。現行比較函式預設取兩個輸出都有紀錄的 ID。[現行計分程式](../medbench/score.py)
4. **量測省下的時間。** 平日先重測受新版指引影響的題目，搭配固定的穩定題追查意外退步。發布正式成績時跑同一版完整保留集。模型版本、提示、題文、工具或證據內容有變就重新作答。僅修正評分標準、且題面與可見證據相同時，可用原始回覆重評。優先用獨立請求併發，以每小時達標題數與醫師複核分鐘數評估效率。共享提示詞的多題實驗另測題間干擾。[批次作答實驗](roadmap.md)

首次發布模型比較時應附題目與證據快照版本、各層分母、待裁決數、抽審覆蓋率及配對結果，再判斷微調是否降低臨床錯誤或虛構引用。首批公費篩檢對照題仍在醫師審查階段，尚無新舊標註的微調比較結果。[對照題與審查狀態](review/tw-fit-controls.md)

## 同一份題本如何比較兩個模型

先用同一份凍結題本分別產生兩份 `clinical_score` 報告，再交給配對比較程式。檔案須有相同的題本 SHA-256、題號集合、內容指紋與病例家族。漏答、格式失敗及過時選項依原判分留在各自應有的分母。下列指令以右側減左側表示差異。

```sh
python -m medbench.clinical_compare --left data/run/old-score.json --right data/run/updated-score.json --out data/run/paired.json
```

比較項目包括臨床達標、結構答案、舊選項沿用、不當棄答、無有效選項辨識、資訊不足辨識及確認虛構的引文。每項以配對矩陣呈現兩組結果、適用分母與待審數。臨床裁決或引用審查有缺時，`bounds_over_unresolved_reviews` 列出依已知判定可推得的整批差異上下界。引用項目在有完整審查且已處理所有待查引用時可判為未發現虛構。有明確證實的虛構引用時可判為有，其餘列為未確定。使用較舊紀錄時可重跑原判分取得新欄位。

待審時點估計與抽樣區間留空。完成裁決且至少有兩個家族時，以整個家族重抽 2,000 次估計百分位區間。同一家族的兩個語言及兩個實驗組一起重抽。區間適用於同樣方式抽樣的病例。若計畫按科別過度抽樣，須另外依設計權重計算。[配對比較程式](../medbench/clinical_compare.py)
