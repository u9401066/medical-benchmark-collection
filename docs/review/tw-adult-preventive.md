# 同為 36 歲，成人預防保健補助間隔如何決定？

兩道原創題都設定在臺灣。個案持有健保資格，無症狀，從未使用這項服務，詢問目前年齡所屬類別可補助的最短例行間隔。比較的兩個截點中，個案條件都固定為 36 歲。每個截點獨立判讀，不追蹤同一人過兩年後的年齡。[一般資格雙語原題](../../drafts/mbc-tw-adult-0001.json) · [小兒麻痺身分雙語原題](../../drafts/mbc-tw-adult-0002.json)
