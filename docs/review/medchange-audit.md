# MedChangeQA 新舊答案實檔稽核

2026-11-26 核對 MedChangeQA 釋出的 512 列歷史配對。**其中 160 列的判定從明確支持或反對，改為證據不足。** 這些標籤描述各版系統性回顧的結論。題庫在建構時就選取判定有變的問題，因此本表無法估計所有醫學考題的過時率。[固定版本原始 CSV](https://github.com/jvladika/MedChange/blob/474f969ade22b8f96a24c3970883e68a6f2799d1/Datasets/MedChangeQA.csv) · [作者的資料建構方法](https://aclanthology.org/2025.findings-emnlp.487/)

| 舊版判定＼新版判定 | 支持 | 反對 | 證據不足 | 舊版合計 |
|---|---:|---:|---:|---:|
| 支持 | 0 | 50 | 102 | 152 |
| 反對 | 65 | 0 | 58 | 123 |
| 證據不足 | 156 | 81 | 0 | 237 |
| **新版合計** | **221** | **131** | **160** | **512** |

**分母與缺口。** 原檔四欄分別為無表頭的列識別值、題幹、新版標籤及舊版標籤，均無空值。512 個列識別值均相異，英文題幹按原字串比對共 502 種。唯一重複的題幹出現 11 次，涵蓋三種不同的新版標籤。僅依題幹去重會遺失脈絡，逐列隨機切分也可能把同一句題幹分到訓練與測試兩側。該檔未附逐列回顧識別碼、證據日期、地區、選項、詳解及引用，無法用它核定某題在臺灣今日的答案，或某句詳解是否獲引文支持。

**用於審題。** 可將直接改變方向的 115 列、轉為證據不足的 160 列、從證據不足變成可判定的 237 列列為三個複核層。每層抽樣核對臨床問題、原回顧及更新版的版本和結論，再加上同期「答案仍正確」的對照，評估模型能否兼顧更新與保留。原考卷若存在「無適當選項」，需由審題者逐一核對既有選項；證據不足標籤本身無法證明各選項皆不成立。

## 重現

從上方固定提交取得 `Datasets/MedChangeQA.csv`，在儲存庫根目錄執行以下命令。工具僅使用 Python 標準函式庫，先核對 SHA-256，再輸出標籤交叉表、缺值及重複筆數。此報告保存聚合資料。[稽核程式](../../scripts/medchange_audit.py)

```sh
python scripts/medchange_audit.py data/discovery/MedChangeQA.csv
```
