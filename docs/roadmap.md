# 評測工具 Roadmap

## 長期研究目標

建立一套能指回第一手資料、由臨床醫師核准、可依日期重建的醫學 AI 與 agent 評測及微調資料庫。

1. 按科別、職類與任務找臺灣及國際來源。從官方名冊、學會與校院公告、公用文件、論文及作者釋出平台追到原件。收錄選擇題、病例、OSCE、開放問答、引用查證與工具任務，分批記錄授權、版本、涵蓋分母、缺口與跨站重複。
2. 與醫師共編臺灣繁中及美式英文題，分別記下作答語言與適用地區。保存原考期答案與給分決議，再就指定日期和族群審定現行答案。審查涵蓋改答、複數有效、無有效選項、資料不足及證據衝突；每項關鍵主張連到可核實的證據。
3. 監測來源內容、依複審日產生待辦，追溯受影響的題目與批次。重新發布前記錄具名核准、修訂或撤回。按病例家族分開訓練、公開開發及保留評估資料，核對各用途的權利和核准紀錄。
4. 在同一批保留病例上比較新舊標註的微調效果，量測臨床正確性、沿用過時答案、適當與過度棄答、無根據主張、虛構引用及醫師工時。測試獨立請求併發、後端批次、前綴快取與多題共用提示詞，記錄速度、成本與題間干擾。
5. 以小批次提交來源、覆蓋統計、證據、人工待審項目與測試結果。每次發布都留下可重跑的版本及續作位置。考選部歷題及待授權的 `medical-bench-tw` 依[交接紀錄](../datasets/moex/RESUME.md)保留，待使用者確認再恢復。

## 當期目標與交接

持續蒐集臺灣及國際的醫學評測。每一批都要留下可重跑的發現紀錄、可定位的證據，以及哪些題目仍需醫師判定。第一階段將檢驗，以指定日期、地區和證據重新審過的題目作微調，能否減少模型沿用過時答案、硬選錯誤選項和提出無根據詳解的情形。

| 階段 | 本批產物 | 下一批從哪裡接手 |
|---|---|---|
| 找來源 | [時效、棄答與詳解核實資料表](../datasets/discovery/temporal-review-sources.tsv)。每週一查最近 14 天新進 PubMed 索引的研究，相鄰兩批有 7 天交疊。 | 依 PMID 去除跨批重複，再核對作者的資料集 DOI、版本、任務、授權與實際可用 split。補查既有[臺灣學會公告](../datasets/tw-societies/exam-sources.tsv)與作者釋出平台。它們有時比期刊索引早。 |
| 更新答案與詳解 | [臺灣公費篩檢題](review/tw-fit-controls.md)涵蓋改答、維持原答和無適當選項。[代謝症候群開放題](review/tw-mets-missing-triglycerides.md)測資料是否足夠。[美國乳房攝影篩檢題](review/us-mammography-interval.md)可比較指定單一機構與同時要求兩機構共識的差異。每週比對這三個家族所用的五個段落。 | 醫師分語言核對個案是否適用原指引、是否有共同建議及各機構來源。需裁定的版本保留在佇列。其他來源持續查核。 |
| 評估改標成效 | [評估方案](temporal-evaluation.md)定義臨床達標、沿用舊答案、適當棄答、詳解證據與審題工時。 | 先鎖定同病例家族的分割，建立醫師審定的保留集，再比較同一基礎模型、等訓練預算下的新舊標註。先導報告揭露各層分母、未核准題數與配對不確定性。 |

每批用 Git 提交固定題本及規則，記下實際審過的語言版本與下一個可執行步驟。每週任務提供候選與警示，審查決議由具名醫師留下。考選部題庫繼續依原交接暫停。[臨床時效維護操作](editorial-workflow.md#臨床時效維護) · [每週查核工作流程](../.github/workflows/clinical-evidence.yml) · [考選部交接](../datasets/moex/RESUME.md)

第二批已補齊同一政策下的三個對照問法，分別測模型能否辨認選項缺了正解、選到更新後的正解、保留仍然成立的舊答案。六個語言版本屬同一病例家族，全部送公開開發審查。後續以其他科別的獨立病例補足缺資訊及證據衝突，保留集另行編題。開發集與保留集的醫師核准匯出，可交由臨床判分器記錄有效作答、錯誤棄答與尚待裁決的詳解。[三題雙語審題單](review/tw-fit-controls.md) · [現行評估與操作方式](temporal-evaluation.md)

第三批收錄麻醉專科口試及核醫臨床評量工具共八份附件的定位與指紋。核醫 DOPS 的表單和說明在同一序號使用不同標頭，須由熟悉該工具的審查者核對評量面向。另有四個待審雙語版本可測資料缺漏與臨界值。PubMed 快照已初篩 22／206 篇，下一筆是 PMID 43086468。[學會原件](../datasets/tw-societies/sources/clinical-assessments.tsv) · [指標計數審題單](review/tw-mets-missing-triglycerides.md) · [兩個病例家族的來源核對](review/tw-fit-mets-watch-2026-11-26.json) · [PubMed 初篩](../datasets/discovery/pubmed/triage.tsv)

第四批核對中臺科技大學護理系兩則公告，九個附件中有六份正式 OSCE 考官評分表，涵蓋四種技能。抽痰表的表頭項數與逐項編號不同，兩種數字都已保留。另以一個美國篩檢病例建立兩個雙語問法，並將三個病例家族的五個來源段落納入當週查核。臺灣公費篩檢題的歷史可比性與舊選項已接入臨床判分流程。下一批優先找「多個選項都確實成立」且有同一適用族群及原始依據的病例，也要逐步補齊評分時如何定位模型理由與來源主張。[OSCE 逐件表](../datasets/tw-societies/sources/osce-nursing.tsv) · [來源監測快照](review/clinical-watch-2026-11-26-us-mammo.json) · [過時選項沿用的分母](temporal-evaluation.md#對一份已分派題本計分)

第四輪文獻初篩後累計 32／206 篇，下一筆是 PMID `43083839`。牙科循證問答可區分 11 個原始問題與 99 次重測作答。雙語醫學考試的上游資料有 8,220 個題號與模型配對，其中 8,208 對中英兩側皆可評分，題文重刊仍須另向原出題機構確認。[雙語作答分母重算](review/bilingual-exam-audit.md) · [逐篇核對與權利狀態](../datasets/discovery/pubmed/triage.tsv)

臺灣公費篩檢的日期實驗已保留同一個模型、六個語言版本在兩個日期、兩種回覆格式下的 24 份原文。指定 JSON Schema 後，英文可解析回答由 0/6 增至 6/6。兩種設定各分派 12 題，兩者與編者擬答一致的可解析回答均為 0 份。後續做題目時效或微調比較，要同時公布格式成功數、過時選項、其他錯誤與醫師裁決分母。[完整對照與重跑方式](../reports/tw-fit-date-probe/README.md)

### 第五批與目前續作位置

臺灣學會與教學機構已定位 104 筆評量來源，涵蓋 64 個機構。這批找到三份藥師 OSCE 工作坊示範站，逐件核對病例、考生指示、考官表、標準化病人腳本及整體評分。PubMed 已初篩 42／206 篇，下次從 PMID `43080534` 接手。MedAESQA 的逐句索引可重建 5,162 句與 9,611 筆引文標註。原檔同一句同一 PMID 有重複與相異標籤，與論文比較時須交代計數單位。[臺灣藥師 OSCE](../datasets/tw-societies/sources/osce-pharmacy.tsv) · [PubMed 初篩](../datasets/discovery/pubmed/triage.tsv) · [MedAESQA 索引與分母](../datasets/discovery/medaesqa/README.md)

美國乳房攝影病例新增兩種作答要求。當兩種排程均符合單一機構指引時，分別測「任舉一種」與「列出全部」。目前共有 11 道概念題、5 個病例家族、22 個待審語言版本。另有 12 份臺灣公費篩檢模型回答可讓醫師先試審，該批審閱完成 0／12。下一步從逐句核對族群與年齡條件開始，留下原回答位置、來源表列、具名決議及實際工時。[雙語複選審題單](review/us-mammography-multiple-options.md) · [模型作答審閱本](../reports/tw-fit-date-probe/review-worksheet.md) · [醫師核對方式](rationale-review.md)

同一小模型另完成 12 次配對推論。在同一臺灣篩檢病例家族的 6 個版本中，閉卷 0／6 選到編者擬答，直接附上國健署服務表後為 4／6。兩個缺少有效選項的版本仍都選錯。後續須累積其他病例家族與醫師已審定的保留題，分別比較是否找對依據、是否正確套用到病人，以及理由能否由證據支持。[逐題對照與研究限制](../reports/tw-fit-date-probe/grounding.md)

## 批次作答的速度與題間干擾

第一輪在一台 CPU 工作機完成。Qwen2.5 1.5B 對兩組各 12 題解剖學題作答，獨立請求併發 2 的整批時間在兩組都最短。Test 單題與雙題共用提示均答對 9/12，卻有兩題改答。單題重跑也出現一題改答，因此下輪須分開控制鄰題、題位與重跑變異。[實測數字、原始回覆與重跑方式](../reports/anatomy-batch-pilot/README.md)

目前 `medbench run` 每題以一則獨立訊息送出，設定檔的 `concurrency` 控制同時在途的請求數。既有工具可量測併發吞吐及長前綴快取。醫學題的共同指令通常很短，題幹、病例與選項仍需各自編碼，實際節省的時間要在題庫上量。[執行器](../medbench/runner.py) · [併發測量](../scripts/slot_sweep.py) · [前綴快取測量](../scripts/prefix_cache.py)

2026-11-26 使用已快取的量化模型及獨立啟動的 llama.cpp 伺服器完成先導，判分依據是 MMLU 作者公布的答案。擴至繁中臨床題時，需先固定醫師已審定的答案及適用日期。後端排程、GPU 效能、前綴快取收益與成本仍待各自實測。

| 實驗條件 | 模型作答時看得到什麼 | 要回答的問題 |
|---|---|---|
| 單題依序 | 自己的題幹與選項 | 同一題重跑，答案本來就會變動多少？整份測驗需要多久？ |
| 獨立題目並行 | 每題仍有獨立上下文。支援 continuous batching 的後端可在同一輪 GPU 運算處理多條序列 | 提高併發後，吞吐、延遲及逐題答案如何變化？完全相同的指令前綴可另測冷、暖快取。 |
| 同一提示詞放多題 | 同批的所有題幹與選項，以及在同一回覆中先生成的答案 | 同一道題單獨答、排第一或排最後，換一組相鄰題後是否改答？ |

固定題庫重跑時，可加測 vLLM 離線批次推論，一次提交一串獨立提示詞。支援 token ID 輸入的後端還可以預先分詞，按 tokenizer 版本和對話模板保存結果，先核對與文字路徑產生的 token ID 完全相同。這可省去重複分詞的 CPU 工作，每道新題的輸入仍需由模型讀取。[vLLM 離線批次範例](https://docs.vllm.ai/en/stable/getting_started/quickstart/) · [可接受的輸入格式](https://docs.vllm.ai/en/stable/api/vllm/inputs/llm/)

後端合批與前綴快取分別影響排程及輸入計算。快取命中可省去相同前綴的重算，後續輸出仍需生成。既有批次提示研究可作為組題方法的起點。[Hugging Face continuous batching](https://huggingface.co/docs/transformers/main/en/continuous_batching) · [vLLM 前綴快取](https://docs.vllm.ai/en/stable/features/automatic_prefix_caching/) · [Cheng 等，EMNLP 2023](https://aclanthology.org/2023.emnlp-industry.74/)

### 第一輪怎麼測

1. 固定同一份有審定答案的選擇題、模型與量化版本、推論後端、硬體、提示範本和解碼設定。先重複單題基準，再以相同題目測獨立併發，例如 1、2、4、8。記錄逐題 seed、後端是否支援、冷暖快取及其他服務負載。[vLLM 批次與可重現性](https://docs.vllm.ai/en/v0.31.0/features/batch_invariance/)
2. 多題共用提示詞時，先以相同格式跑每批 1 題作為對照，再試每批 2、4、8 題。固定目標題，輪替首、中、末位置，分別配同科和跨科、長度相近的獨立題。繁中與英文分層。同病例連題、同題翻譯及會提示彼此答案的題目另組。每批記錄題序、批次 seed、上下文長度，按題數配置可比較的輸出預算。
3. 每批回傳題目 ID 與答案，逐題驗證缺答、重複 ID、未知 ID 及截斷，保存原始輸出。現有單題解析器只取最後一個答案。實作時各條件使用獨立執行目錄與提示版本，讓同一題在不同條件下都能評分及續跑。

### 報告指標

- **效率**用相同題集的總牆鐘時間、每小時完成題數、每小時答對題數及 p95 延遲衡量。另記輸入與輸出 token、首 token 時間、峰值顯存，以及後端實際回報的快取命中量。多題共用回覆時，首 token 與完成延遲以整批為單位。
- **題間干擾**以同一目標題配對。答案翻轉率為「選項有變的題數 ÷ 兩條件都能解析的配對題數」，並列配對分母、原本答對後改錯及原本答錯後改對的數量。與同格式單題重跑的翻轉率對照，再按題位、同科或跨科比較。即使總正確率持平，也能看出哪些題互相抵銷。
- **成績與採用條件**以全體目標題計正確率，缺答或無法唯一歸戶的題目計錯，另列缺答與錯配率。第一輪事先訂出可接受的正確率下降及翻轉幅度，再給出配對差與信賴區間。同一批的題目可能一起受影響，估計不確定性時保留整批及重複組題的關係。正式單題分數與共享上下文實驗各自報告。
